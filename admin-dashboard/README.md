# Vaila Teaching Admin Dashboard (Next.js + TypeScript)

Web administrative portal for teachers, speech therapists, and parents to review pronunciation performance of hearing-impaired children.

## Features
- **Live Accuracy Log Stream**: Monitors speech attempts in real-time.
- **Pass Threshold Metrics**: Tracking 90%-100% pronunciation score benchmark.
- **Rule Verification**: Displays audio repetition rules and vibration status.

## Getting Started

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Run dev server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:3001` in your browser.
